# 台灣大樂透新世代鐵律預測系統

本系統為全新獨立運算核心，只使用台灣彩券官方歷史開獎資料，不沿用任何舊預測函式。

## 運算與驗證

- 2,155期以上正式歷史資料，起始2007-01-02；每次更新以官方API最新有效期為準。
- 主號與特別號分開建立模型、回測及排名。
- Bayesian平滑、四段EWMA、實證遺漏風險、條件共現與趨勢狀態模型。
- 每期只能使用之前資料；獨支使用1,040期走步驗證，固定拆成較舊520期開發段與最新520期保留段。
- 模型權重依20／60／120期前9碼表現決定，單一模型不得超過25%。
- 第10–15名命中不再算成功，逐期列為邊界外溢並對責任模型扣分。
- 校準機率分數固定占75%、跨模型順位固定占25%；前9邊界固定壓縮4席。
- 前9碼最多沿用上期3席，避免上一期結果過度擠占短包。
- 發布前強制納入最新一期重算權重，修正舊版權重延遲一期問題。
- 外部分析模式必須先通過無未來資料的雙區段驗證；軌跡、星期週期、拖牌、鄰號、間隔與共現規則必須在兩個520期都勝過6/49，否則禁止進入正式預測。
- 機率向公平開獎先驗收縮80%，避免製造虛假高信心。
- 發布門檻未通過時，禁止覆蓋最後一份有效手機戰報。
- 每期固定輸出唯一一顆「終極獨隻・全系統最高順位」，並完整列出證據。終極獨隻是全系統本期唯一第一順位；回測信心另外獨立標示。只有最終順位、多模型共識、開發520期、保留520期及多條件軌跡規則全部通過，回測信心才准顯示完整通過，禁止宣稱90%或保證命中。
- 獨隻卡固定同區顯示適用開獎日、依據期別、官方資料截止日及台灣時間運算時間；缺少任一日期欄位即禁止發布。
- 所有已登錄核心與公開可重現候選模組每天全部運算並逐項列出候選、權重及狀態；沒有通過雙區段驗證的軌跡模組權重固定為0，禁止用失敗模組製造虛假共識。

每次發布都重新執行主號1,040期與特別號520期走步驗證：主號前9碼平均命中對照隨機基準1.1020，另獨立公布第10–15名平均外溢；特別號前三碼對照隨機基準0.0612。這是歷史驗證結果，不代表未來保證。

## 戰報規格

核心決策、逐號驗算、短包強牌、低機率獨立區、上期誤開檢討、戰果驗算、模型回測、每月總結、鐵律守門與預測生命週期。

## 執行

```powershell
python update.py
python verify.py
```

GitHub Actions每天台灣時間00:05強制重新運算並發布當日戰報，另每3小時檢查一次；即使沒有新開獎，也不得沿用前一日的運算日期。同一日且官方資料未變時不製造重複提交。週二、週五21:25至22:30每5分鐘加密輪詢；台灣時間22:30仍未更新即啟動自主修復。官方資料完整性與模型可信度分開守門；即使模型未達超強門檻，最新合法開獎資料仍必須同步，戰報則如實降級。

獨立手機雲端版位於 `mobile_cloud`，Pages專屬入口為 `/mobile_cloud/`，並與電腦戰報逐檔同步驗證。

手機頁面禁止快取舊戰報；每次開啟、由背景回到前景及每60秒都會查詢雲端版本，發現新版本立即重新載入。

手動更新按鈕會跳過快取，同時核對版本、期別與全系統自測；有新版才重新載入，已是最新版時會保留完成時間並明確顯示「目前已是最新」，不再點擊後無條件重載而看不到結果。

## 不可變動的自動更新鐵律

`IRONLAW.json` 鎖定官方抓號、資料驗證、上期結算、全量重算、五處同步、失敗禁止發布與保留最後有效戰報。發布流程會逐次檢查這些規則，任何一條缺少即中止。

第7版鐵律採用六合彩戰報相同的酒紅色頁首、六分頁導覽、最強獨支大卡、完整牌組表、摺疊證據區、回測驗證、開獎檢討、歷史封存、模型說明與系統健康版面。完整雲端防線包含跨月補抓、無新期別不提交、官方CSV與分析／歷史結算逐筆一致性、五端檔案雜湊同步、失敗原子回復、線上手機雲端版本比對，以及新版推送後立即驗證、失敗最多3次自動重建。手機與完整戰報固定提供「手動更新最新」及「當機立即修復」按鈕；成功後保留台灣時間，未通過不得假報成功。發布前另執行程式語法、相依套件、JSON、JavaScript、工作流程目標、暫存殘留與五端同步故障掃描。

每期開獎後會用開獎前封存的各模型第一名與候選區逐一結算，輸出命中、對數損失、調整前後權重與處置。最強獨支固定只輸出一個順位；上期獎號只允許用於結算與追責，禁止直接當成下期推薦捷徑。

第9版把獨支驗證擴充成雙區段：現行選擇器在較舊520期為54中（10.3846%），最新520期為77中（14.8077%），合計131/1,040（12.5962%）。系統每期仍固定輸出全系統唯一第一順位的終極獨隻；較舊區段低於6/49隨機基準12.2449%時，回測信心獨立標為審慎級，不得拿最新區段的77/520冒充穩定能力。戰報同時逐項公開星期週期、一階／二階拖牌、鄰號軌跡、間隔復現、共現拖牌與多條件混合的開發／保留結果；兩段沒有同時勝出的規則一律淘汰。

近期命中偏低時採20／60／120期多尺度權重：最近20期占50%、60期占30%、120期占20%，並加入第10–15名外溢懲罰、連續零命中懲罰、固定4席邊界壓縮、上期號最多3席、模型穩定度懲罰與單模型25%上限。每期戰報固定顯示前9邊界稽核、本期升降號碼與雙區段獨支驗證；任何新規律都必須重新通過開發段及保留段，禁止用單一近期區間製造虛假高命中率。
