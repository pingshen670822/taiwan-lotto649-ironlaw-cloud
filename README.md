# 台灣大樂透新世代鐵律預測系統

本系統為全新獨立運算核心，只使用台灣彩券官方歷史開獎資料，不沿用任何舊預測函式。

## 運算與驗證

- 2,155期以上正式歷史資料，起始2007-01-02；每次更新以官方API最新有效期為準。
- 主號與特別號分開建立模型、回測及排名。
- Bayesian平滑、四段EWMA、實證遺漏風險、條件共現與趨勢狀態模型。
- 每期只能使用之前資料，以520期時間序列走步驗證。
- 模型權重依20／60／120期前9碼表現決定，單一模型不得超過25%。
- 第10–15名命中不再算成功，逐期列為邊界外溢並對責任模型扣分。
- 校準機率分數固定占75%、跨模型順位固定占25%；前9邊界固定壓縮4席。
- 前9碼最多沿用上期3席，避免上一期結果過度擠占短包。
- 發布前強制納入最新一期重算權重，修正舊版權重延遲一期問題。
- 外部分析模式必須先通過無未來資料的520期走步驗證；沒有提升既有基準就禁止進入正式預測。
- 機率向公平開獎先驗收縮80%，避免製造虛假高信心。
- 發布門檻未通過時，禁止覆蓋最後一份有效手機戰報。
- 每期固定輸出唯一一顆「系統內相對超高信心」強推號，必須同時通過最終順位、多模型前9／前15共識與520期能力門檻，並完整列出證據；此標籤不代表中獎保證。

每次發布都重新執行520期走步驗證：主號一律以前9碼平均命中對照隨機基準1.1020，另獨立公布第10–15名平均外溢；特別號前三碼對照隨機基準0.0612。這是歷史驗證結果，不代表未來保證。

## 戰報規格

核心決策、逐號驗算、短包強牌、低機率獨立區、上期誤開檢討、戰果驗算、模型回測、每月總結、鐵律守門與預測生命週期。

## 執行

```powershell
python update.py
python verify.py
```

GitHub Actions每3小時檢查一次；週二、週五21:25至22:30每5分鐘加密輪詢。台灣時間22:30仍未更新即視為超過開獎後120分鐘，啟動自主修復：每10分鐘重跑官方抓號、全量重算、完整驗證與五處同步，單次連續重試3輪。只有官方資料驗證、520期能力門檻與全部自測通過後才會同步手機雲端。

獨立手機雲端版位於 `mobile_cloud`，Pages專屬入口為 `/mobile_cloud/`，並與電腦戰報逐檔同步驗證。

手機頁面禁止快取舊戰報；每次開啟、由背景回到前景及每60秒都會查詢雲端版本，發現新版本立即重新載入。

## 不可變動的自動更新鐵律

`IRONLAW.json` 鎖定官方抓號、資料驗證、上期結算、全量重算、五處同步、失敗禁止發布與保留最後有效戰報。發布流程會逐次檢查這些規則，任何一條缺少即中止。

每期開獎後會用開獎前封存的各模型第一名與候選區逐一結算，輸出命中、對數損失、調整前後權重與處置。最強獨支固定只輸出一個順位；上期獎號只允許用於結算與追責，禁止直接當成下期推薦捷徑。

近期命中偏低時採20／60／120期多尺度權重：最近20期占50%、60期占30%、120期占20%，並加入第10–15名外溢懲罰、連續零命中懲罰、固定4席邊界壓縮、上期號最多3席、模型穩定度懲罰與單模型25%上限。新版520期前9平均命中由1.1692提升至1.1788，最近20期由1.15提升至1.35；這是歷史走步結果，不是未來中獎保證。每期戰報固定顯示邊界稽核與本期升降號碼，所有變更必須重新通過520期走步驗證。
